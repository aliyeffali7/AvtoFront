# AvtoFront – Servo frontend

This is the web frontend of **Servo**, a multi-tenant SaaS CRM for auto repair shops in Azerbaijan. The UI is in Azerbaijani and works on desktop and mobile.

The backend (Django REST Framework) is private. The project is explained in [servo-showcase](https://github.com/aliyeffali7/servo-showcase).

Live: [avto-front.vercel.app](https://avto-front.vercel.app)

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- Deployed on Vercel

## Main screens

- Reservations and orders, with full repair history per car
- Services and parts on each order, payments and discounts
- Warehouse (stock) and daily finance
- Admin panel for the platform owner
- Printable order PDF (service act) and WhatsApp share link

## Run locally

```bash
npm install
npm run dev
```
